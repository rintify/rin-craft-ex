# FOLD Studio

スマートフォンから使える、静的な3Dモデリング・展開図エディタ。Vite / React / TypeScript / Three.jsで構成しています。

```sh
npm ci
npm run dev
npm test
npm run build
```

`dist/`をそのまま静的ホスティングできます。相対URLなのでサブディレクトリにも配置できます。サーバー処理、アカウント、オンライン保存、外部フォントは使いません。編集データは端末内に自動保存し、JSON・OBJとして持ち出せます。

## 操作

- 左スティックで視点回転、右スティックで連続ズーム。回転は最大0.8rad/秒、ズームは最大入力で1秒につき距離が1/2または2倍。回転・ズーム量は倒した量と時間で決まります。タッチ、マウス、キーボードに対応。
- 点を複数選択、空白で作業基底上に点を作成。「見る」で選択点の平均位置、未選択なら基底原点を向きます。カメラの距離を自動調整する操作は別の「全体を表示」です。
- 基底を最初の選択点へ移動、基底軸を循環して回転、選択点が属する形をまとめて削除。
- ＋から基本形状6種類。追加位置はカメラの正面100mm。形状の移動・回転・倍率、数値入力、頂点移動、面の押し出し・差し込み・三角分割、反転、複製、表示切替。
- 上部のUndo / Redoは80操作。読み込み、削除、設定変更、一括AI編集も対象。カメラや選択は履歴を消費しません。
- ヒエラルキーとインスペクターは常時表示。縦長のスマートフォンでは作業画面の下に並び、横長画面では左右に配置します。それぞれ独立してスクロールできます。追加・ファイル操作は自作ダイアログにまとめています。
- 視点の切り替え・「見る」・全体表示は560msで補間し、指の入力で途中から引き継げます。UIは共通の240ms遷移で開閉・内容変更を処理します。展開図は計算中も直前の結果を表示し、古い結果の編集・書き出しを止めます。
- プルダウン、ダイアログ、開閉セクション、スイッチは自作。キーボード選択、Esc、フォーカス復帰、モーダル内のTab移動に対応しています。ファイルは貼り付け・ドロップで読み込めます。端末の任意ファイルを選ぶ操作だけはブラウザの保護されたファイル選択画面を使います。
- PDFは自作の書き出し画面で生成し、表示されたリンクから保存します。ネイティブ印刷ダイアログは呼び出しません。線はベクター、文字は600dpiで、外部フォントの取得は不要です。

## 展開図

面は無色。切断は黒、山折りは赤、谷折りは青の実線です。面の素材・テクスチャー・着色、のりしろ、接着番号の生成処理はありません。

展開アルゴリズムは共有辺のグラフをたどり、凸多角形の交差判定で重複を避けながら連続した部品を作ります。展開する段階では用紙の大きさに制限しません。収まる部品を回転・配置し、収まらない部品は実寸のまま複数ページへ分割します。

分割ページは図形を10mm重ねて出力。対応する2組の紫の十字・IDを合わせます。必要な紙端の余白を切り落とし、紫の線を目安に重ねて固定します。ページの下端12mm以上は凡例・確認目盛り用です。印刷倍率は100%（実際のサイズ）にし、20mmの確認線を測ってください。

微小辺の初期値は実寸1mm、設定で変更できます。オブジェクトの倍率を適用した3Dの長さで判定し、印刷倍率は影響しません。短辺が1本の三角形の連続部分は曲面として接続を優先し、内部線を出しません。対辺2本が短い四角形も円柱の帯として扱います。短辺が2本以上の三角形は読み込み・編集時に拒否します。

## モジュール

| 場所 | 責務 |
| --- | --- |
| `src/core/types.ts`, `project.ts`, `settings.ts` | 保存形式・検証・旧形式の不要フィールド除去 |
| `src/core/geometry.ts`, `meshOperations.ts`, `surfaces.ts` | 形状操作・微小辺・曲面の判定 |
| `src/core/unfold.ts` | 立体から連続した平面部品を作成 |
| `src/core/pagination.ts`, `clipping.ts`, `packing.ts` | 実寸配置・分割・位置合わせ |
| `src/core/svg.ts` | プレビュー・SVG・印刷共通の描画 |
| `src/state/editor.ts`, `workspace.ts` | 原子的な編集・Undo/Redo・選択点と基底 |
| `src/scene/` | GPU・3Dのポインター処理・カメラ計算 |
| `src/components/`, `primitives/` | 常時表示パネル・共通UI・開閉と内容遷移 |
| `src/io/pdf.ts` | 共通SVGから実寸PDFを生成（遅延読込） |
| `src/workers/`, `src/hooks/useNet.ts` | 展開計算の分離と古いリクエストの破棄 |
| `scripts/`, `src/state/webmcp.ts` | CLI・AI操作API |

## 検証とサンプル

`npm test`で辺長・面積・重複・ページ範囲・分割目印・曲面の連続性・微小三角形禁止・履歴・操作速度を検証します。`npm run format`で共通の書式に整えます。

`npm run example:gundam`で無色のガンダム頭部サンプルと展開図を再生成します。14部品・92面、130×126×72mm、A4で3ページ。画面の「メニュー → サンプル・その他」から読み込めます。

AIによる自動生成・検査・出力は [docs/AI_WORKFLOW.md](docs/AI_WORKFLOW.md) を参照してください。
